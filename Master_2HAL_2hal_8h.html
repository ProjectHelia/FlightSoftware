bool hal_init ( void  )

Bring up the CAN bus and the TT&C Ethernet link.

Returns
False only if CAN failed - that's fatal, Master is useless without the bus. A failed Ethernet bring-up is logged but not fatal: Master must keep running CAN/flight logic with no ground link, since link loss is an expected degraded state (the flight manager holds phase until reconnection), not a reason to halt.
