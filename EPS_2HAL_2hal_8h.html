Detailed Description

EPS hardware interface.

Implemented by HAL/esp32/hal_esp32.c on the board and HAL/sim/hal_sim.c on a laptop; the build links one of them.

Functions return raw physical measurements. Turning those into current and temperature is done in control.c, where it can be unit-tested.
