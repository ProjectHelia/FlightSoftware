Detailed Description

HELIA CAN protocol constants: the SED's 11-bit ID scheme and message dictionary This is supposed to be the single source of truth for the entire CAN protocol.

If anything changes in here then all codes should be recompiled to match! Any SEDS changes should be reflected here also
