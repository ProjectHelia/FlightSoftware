Detailed Description

Convert an NTC thermistor voltage-divider reading to degC using the Beta equation.

Shared: EPS, Master, Mechanisms and Thermals all have NTC thermistors.

Beta equation: 1/T = 1/T0 + ln(R/R0)/B (T in kelvin)
