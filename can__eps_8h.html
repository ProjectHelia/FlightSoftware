Detailed Description

EPS message payloads.

Shared so EPS encodes and Master decodes with the same code.

EPS_STATUS payload (6 bytes, little-endian): [current_ma i16][shunt_mv_x100 i16][temp_c_x10 i16] A value with no valid reading is sent as UTIL_I16_INVALID (INT16_MIN).
