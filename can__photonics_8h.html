Detailed Description

Photonics telemetry (source 0x4) encode/decode.

Pure - no FreeRTOS, no I2C - same tier as can_instr.c/can_eps.c.

The SED's Photonics CAN Message Dictionary (0x01-0x06: PD_DATA, PD_AVG_DATA, UV_STATUS, EVENT_EXPOSURE_*) describes the full flight photodiode array (8 photodiodes x 8 flasks via a mux, 64 channels) and an active UV exposure sequence (elapsed time + dose). What's actually on this board right now is different hardware: two LTR390 ambient-light/UV sensors and an onboard ADS1115 - so none of those SED message shapes fit. Picked fresh type IDs after the SED's reserved range rather than force the data into a mismatched shape; the SED needs a table update once the real photodiode array comes online.
